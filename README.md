# Task Manager

A single-page task manager built with vanilla HTML, CSS and JavaScript. Tasks are saved in the browser's `localStorage`, so your list survives a page refresh with no backend required.

## Features
- Add, complete, and delete tasks
- Filter by all / active / completed
- Persisted locally in the browser
- Responsive, works on mobile

## Run it
No build step needed — it's plain HTML/CSS/JS.

```bash
git clone https://github.com/workwithpranayaa-dotcom/task-manager.git
cd task-manager
# open index.html in your browser, or serve it:
python -m http.server 8000
```

Then visit `http://localhost:8000`.
